# kana-decoder

日本語かな漢字変換デコーダ。ひらがな文章を、文脈に適合した漢字・かな表記と句読点を持つ文章へ変換する軽量エンジンを目指します。

## 設計目標

- ひらがな入力からのかな漢字変換
- 同音異義語の局所文脈推定・補正
- ホットワードの実行時注入
- 句読点・文境界の推定
- CPUのみ・完全オフライン
- C++コア + C API
- 1文節あたり1 ms未満を性能目標とする（実測による検証が必要）

大規模生成モデルやネットワーク接続を必須とせず、辞書候補ラティス、接続コスト、局所文脈スコアを組み合わせる設計です。
